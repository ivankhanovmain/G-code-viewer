# G-code-viewer
Профессиональный редактор управляющих программ для станков с ЧПУ. Позволяет создавать и изменять G-код, выполнять поиск и сравнение файлов, перенумерацию кадров и проверку синтаксиса. Визуализация траектории инструмента и моделирование обработки помогают выявлять ошибки до запуска станка.
