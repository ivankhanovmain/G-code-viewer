# Контур

Настольный редактор программ ЧПУ с просмотром траекторий для трёхосевого фрезерования. При запуске открывается [пример фрезерования монтажной пластины](examples/mounting_plate.nc).

## Запуск

Портативные сборки для Windows и Linux доступны в разделе [Releases](https://github.com/ivankhanovmain/G-code-viewer/releases).

Для запуска из исходников нужны Node.js 22.12 или новее и npm.

```sh
npm ci
npm start
```

`npm start` собирает интерфейс и открывает окно Electron. Редактор работает с локальными файлами. Сеть требуется для установки зависимостей и загрузки Electron при первом запуске.

`npm run dev` запускает интерфейс в браузере для разработки. В браузере сохранение загружает файл через менеджер загрузок.

## Возможности

- Вкладки, подсветка G-кода, отмена и повтор изменений, поиск с учётом регистра и замена.
- Открытие и сохранение программ до 4 МиБ в UTF-8 и Windows-1251. Поддерживаются BOM в UTF-8 и окончания строк LF, CRLF и CR.
- Сравнение по строкам с открытой вкладкой или отдельным файлом. Изменённые строки можно показать отдельно.
- Перенумерация и удаление номеров кадров `N`. Для программ с распознанными переходами по номерам кадров эти операции заблокированы.
- Диагностика с переходом к строке и столбцу. Ошибки формата и геометрии дуг показаны отдельно от предупреждений о командах вне поддерживаемого подмножества.
- Вращаемый 3D-вид, проекции XY, XZ и YZ, отдельное отображение резания и холостого хода. Воспроизведение поддерживает пошаговый режим, перемотку и изменение скорости.

## Поддерживаемый G-код

Траектория строится по координатам XYZ и командам G00–G03, включая дуги IJK и R, окружности и винтовые перемещения. Учитываются плоскости G17–G19, единицы G20/G21, режимы G90/G91 и режимы центра дуги G90.1/G91.1. Координаты в просмотрщике приведены к миллиметрам. Длительность рассчитана ориентировочно по запрограммированной подаче и условной скорости холостого хода.

В этой версии симуляция ограничена номинальной геометрией. Макросы, вызовы подпрограмм, станочные циклы, коррекции инструмента, геометрия оснастки и проверка столкновений выходят за её рамки.

## Проверка и сборка

```sh
npm test
npm run build
npm run package
```

Портативная сборка для текущей платформы появится в каталоге `out/`. Для сборки под другую платформу укажите цель, например `npm run package -- win32 x64` для Windows x64 или `npm run package -- linux x64` для Linux x64. На Windows распакуйте весь каталог, затем запустите `Kontur.exe`. Устанавливать Node.js для портативной сборки не требуется.
